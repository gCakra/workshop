Materi: Form Dasar & Input Teks

Form digunakan untuk mengumpulkan data dari pengguna.

Elemen Penting:

  • <form>: Pembungkus seluruh isian formulir.
  • <label>: Memberi nama pada input agar user tahu apa yang harus diisi.
  • <input type="text">: Kotak isian teks biasa.
  • <input type="email">: Kotak isian khusus format email.
  • <button type="submit">: Tombol untuk mengirim form.
