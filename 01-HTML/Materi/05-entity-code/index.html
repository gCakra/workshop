HTML Entity Code

Entity code digunakan untuk menampilkan karakter yang sudah "dipesan" oleh HTML (seperti < dan >) atau karakter yang tidak ada di keyboard.

1. Kenapa Kita Membutuhkannya?

Jika kita menulis

secara langsung, browser akan menganggapnya sebagai tag. Tapi jika kita ingin MENAMPILKAN tulisan

, kita harus menulis: &lt;p&gt;
