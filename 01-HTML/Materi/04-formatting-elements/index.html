Elemen Pemformatan Teks (hr, br, sup, sub)

1. Element <br> (Line Break)

Gunakan ini untuk pindah baris tanpa membuat paragraf baru.
Contoh: Baris ini berada tepat di bawah baris sebelumnya tanpa spasi paragraf.

2. Element <hr> (Horizontal Rule)

Lihat garis di atas? Itu adalah <hr>. Digunakan untuk memisahkan topik atau bagian secara visual.

3. Element <sup> (Superscript)

Digunakan untuk teks kecil yang posisinya di atas.
Contoh Matematika: 102 = 100
Contoh Catatan Kaki: Referensi[1]

4. Element <sub> (Subscript)

Digunakan untuk teks kecil yang posisinya di bawah.
Contoh Kimia: H2O (Air)
Contoh Rumus: Log10 100 = 2
