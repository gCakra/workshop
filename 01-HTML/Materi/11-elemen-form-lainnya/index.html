Materi: Elemen Form Lanjutan

Setelah belajar input teks, sekarang kita akan mempelajari elemen input lainnya yang sering digunakan dalam website.

Penjelasan Elemen:

  • <input type="radio">: Digunakan untuk memilih satu dari beberapa pilihan (harus punya name yang sama).
  • <input type="checkbox">: Digunakan untuk memilih satu atau lebih pilihan.
  • <select> & <option>: Membuat menu pilihan drop-down.
  • <textarea>: Kotak input untuk teks yang panjang (multi-line).
