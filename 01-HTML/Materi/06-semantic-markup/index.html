Judul Website (Header)

Gunakan tag <header> untuk bagian pengantar atau navigasi utama.

  • Beranda
  • Materi
  • Kontak

Tag <nav> khusus untuk menu navigasi.

Konten Utama (Main)

Tag <main> hanya boleh ada SATU di setiap halaman. Isinya adalah konten unik halaman tersebut.

Bagian Artikel (Section)

Gunakan <section> untuk mengelompokkan konten yang berkaitan secara tematik.

Postingan Blog (Article)

Tag <article> digunakan untuk konten yang bisa berdiri sendiri (seperti berita, blog post, atau komentar).

Info Sampingan (Aside)

Digunakan untuk konten yang berkaitan secara tidak langsung dengan konten utama (seperti iklan, link populer, atau profil penulis).
