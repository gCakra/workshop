Perbedaan Element Block dan Inline

1. Block-level Element (Contoh: <div>)

Perhatikan bagaimana kotak merah (div) memanjang ke samping memenuhi seluruh layar meskipun teksnya sedikit.

Saya adalah DIV pertama
Saya adalah DIV kedua (saya otomatis turun ke baris baru)

2. Inline Element (Contoh: <span>)

Perhatikan bagaimana kotak hijau (span) hanya selebar teksnya saja dan tidak memaksa baris baru.

Saya adalah SPAN pertama Saya adalah SPAN kedua (saya tetap di baris yang sama)

3. Kenapa ini Penting?

Biasanya kita menggunakan <div> sebagai pembungkus besar (layout) dan <span> untuk mewarnai atau mengatur sebagian kecil teks di dalam paragraf.
