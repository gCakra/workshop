# Progres Belajar Web Development

Dokumen ini mencatat perkembangan pembelajaran web development, mencakup HTML, CSS, dan teknologi terkait lainnya.

## Ringkasan Proyek
Proyek ini berisi kumpulan latihan dasar untuk memahami struktur web (HTML) dan gaya visual (CSS). Fokus utama saat ini adalah membangun pondasi yang kuat dalam pembuatan elemen web dan tata letak sederhana.

## Struktur Folder
- `01-html/`: Materi dasar HTML.
  - `01-perkenalan/`: Dasar-dasar tag HTML (heading, paragraf, list, dll).
  - `02-multi-halaman/`: Navigasi antar halaman, link, tabel, dan gambar.
- `02-css/`: Materi dasar CSS.
  - `01-css-dasar/`: Penentuan warna latar belakang, font, dan styling elemen dasar.

## Struktur Belajar
- `Materi`: Fokus pada pemahaman konsep baru.
- `Tantangan`: Fokus pada implementasi dan problem solving (cek `CHALLENGES.md`).
