# 🧭 Peta Jalan Belajar Web Development

Selamat datang di kurikulum belajarmu! Struktur ini dirancang agar kamu tahu mana tempat untuk **Eksplorasi (Materi)** dan mana tempat untuk **Pembuktian (Challenge)**.

## 📂 Struktur Utama
- `01-HTML/`: Fondasi struktur web.
- `02-CSS/`: Seni menghias website.
- `03-JS/`: Logika dan interaktivitas.
- `00-Projects/`: Gabungan semua ilmu menjadi satu aplikasi utuh.

---

## 🛠️ Alur Belajar
1.  **Pelajari**: Masuk ke folder `Materi` di setiap kategori untuk mencoba kode baru.
2.  **Uji**: Selesaikan tugas di folder `Challenge` untuk memantapkan pemahaman.
3.  **Bangun**: Jika sudah siap, kita buat proyek besar di `00-Projects`.
