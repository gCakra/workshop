Modul 3: Properti Display

Properti display menentukan bagaimana sebuah elemen ditampilkan di layar dan bagaimana ia berinteraksi dengan elemen di sekitarnya.

1. Display: Block

Elemen block selalu mulai di baris baru dan mengambil lebar penuh.

Kotak 1 (Block)
Kotak 2 (Block)

2. Display: Inline

Elemen inline tidak mulai di baris baru dan lebarnya hanya selebar kontennya. Margin/Padding vertikal tidak berpengaruh sempurna.

Inline A Inline B

3. Display: Inline-Block

Gabungan keduanya: Tetap sejajar (inline) tapi bisa diatur Width, Height, Margin, dan Padding-nya (block).

🛠️ Tugas Eksperimen:

  1. Block: Pada .box-block, atur lebar menjadi 200px. Lihat apakah mereka tetap bertumpuk?
  2. Inline: Pada .box-inline, coba berikan width: 100px; height: 100px;. Apakah berubah ukurannya? (Spoiler: Tidak akan).
  3. Inline-Block: Ubah .box-inline-block agar punya width: 100px dan height: 50px. Lihat perbedaannya dengan elemen inline biasa.
  4. Magic: Ubah .box-block menjadi display: inline-block;. Apa yang terjadi?
