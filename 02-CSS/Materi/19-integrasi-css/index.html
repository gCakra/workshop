🛠️ Tugas Arsitek (Eksperimen):

  1. Buka style.css.
  2. Langkah 1: Gunakan Flexbox pada body untuk menempatkan kartu tepat di tengah layar.
  3. Langkah 2: Berikan warna latar belakang, bayangan (box-shadow), dan lengkungan (border-radius) pada .card.
  4. Langkah 3: Atur .social-links agar tombol-tombolnya berjejer rapi menggunakan Flexbox.
  5. Langkah 4: Tambahkan efek transisi dan hover agar kartu terasa "hidup".

💡 Analogi Mentor:
HTML ini adalah tembok batunya. CSS yang akan kamu tulis adalah cat, plester, dan dekorasinya. Tanpa struktur HTML yang benar, catmu tidak punya tempat untuk menempel!
