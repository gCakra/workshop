Modul 3: Properti Border

Border tidak hanya sekadar garis. Kamu bisa mengatur ketebalan, gaya, warna, hingga membuat sudutnya melengkung.

Solid Border
Dashed Border
Dotted Border
Rounded Corners
Circle

🛠️ Tugas Eksperimen:

Buka style.css dan selesaikan tantangan berikut:

  1. Solid: Berikan border 4px, solid, warna #e74c3c.
  2. Dashed: Berikan border 2px, dashed, warna #27ae60.
  3. Dotted: Berikan border 3px, dotted, warna #f39c12.
  4. Rounded: Gunakan border-radius: 15px; pada box .rounded.
  5. Circle: Buatlah box .circle menjadi bulat sempurna menggunakan border-radius (Hint: 50%).

💡 Tip: Kamu bisa mengatur sisi tertentu saja, contoh: border-top, border-bottom-left-radius, dll.
