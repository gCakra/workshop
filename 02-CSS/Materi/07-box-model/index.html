Modul 3: CSS Box Model

Setiap elemen dalam HTML dianggap sebagai sebuah kotak (box). Memahami Box Model adalah kunci utama dalam mengatur tata letak (layout) CSS.

KOTAK TARGET

🛠️ Tugas Belajar:

Edit file style.css untuk memodifikasi elemen .target-box di atas:

  1. Content: Berikan background-color: #3498db; dan color: white; agar teks terlihat.
  2. Padding: Berikan ruang di dalam kotak sebesar 20px di semua sisi.
  3. Border: Tambahkan garis tepi setebal 5px solid berwarna #2c3e50.
  4. Margin: Berikan jarak di luar kotak sebesar 50px agar tidak menempel ke elemen lain.
  5. Width & Height: Atur lebar kotak menjadi 200px.

💡 Ingat: Total lebar sebuah elemen = width + padding + border + margin.
