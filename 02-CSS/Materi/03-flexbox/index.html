Langkah Belajar:

  1. Aktifkan Flexbox pada .container dengan display: flex;.
  2. Lihat bagaimana item-item tersebut berjejer secara horizontal.
  3. Coba gunakan justify-content untuk mengatur posisi horizontal.
  4. Coba gunakan align-items untuk mengatur posisi vertikal.
