Materi 14: Justify Content

Properti justify-content digunakan untuk mengatur perataan item di sepanjang Main Axis (sumbu utama).

🛠️ Tugas Eksperimen Perataan:

  1. Buka style.css.
  2. Coba ganti justify-content: flex-start; menjadi center.
  3. Coba gunakan space-between, space-around, dan space-evenly. Amati perbedaannya pada jarak antar item.

💡 Nilai Populer:
1. flex-start (default): Rata kiri/awal.
2. flex-end: Rata kanan/akhir.
3. center: Rata tengah.
4. space-between: Jarak maksimal di antara item.
5. space-around: Jarak di sekeliling item.
6. space-evenly: Jarak rata di semua sisi.
