🛠️ Tugas Eksperimen Responsive:

  1. Buka style.css.
  2. Cek tampilan saat layar lebar (Desktop).
  3. Gunakan @media (max-width: 600px) untuk mengubah layout menjadi kolom saat di HP.
  4. Cobalah ubah ukuran browser kamu untuk melihat perubahannya!

💡 Info Mentor:
Media Query adalah "jembatan" yang membuat website kamu bisa berubah bentuk sesuai ukuran layar. Tanpa ini, website kamu akan terlihat sangat kecil dan sulit dibaca di HP.
