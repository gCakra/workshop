🛒 Tantangan: Kasir Toko Mini

Selamat datang di tantangan baru, Garda! Kamu ditantang untuk membuat aplikasi kasir sederhana.

📋 Aturan Main & Fitur Aplikasi:

  1. Program terus berjalan meminta input nama barang dan harga barang menggunakan prompt().
  2. Program akan terus meminta input selama user tidak mengetik kata "selesai" pada nama barang.
  3. Setiap barang dan harga yang diinput harus dimasukkan ke dalam list/array belanjaan.
  4. Ketika user mengetik "selesai":
    • Program berhenti meminta input.
    • Tampilkan struk belanjaan di console / alert berisi daftar barang, harga masing-masing, dan total harga keseluruhan yang dihitung menggunakan perulangan (rekomendasi: pakai for...of yang baru kamu pelajari atau for biasa).

Buka file script.js di folder ini untuk mulai ngoding!
