Materi 29: Tipe Data Boolean

Boolean hanya memiliki dua nilai: true (benar) atau false (salah). Ini adalah fondasi dari semua logika komputer.

📝 Tugas Mentor:

  1. Buka script.js.
  2. Buat variabel yang menyatakan status (misal: apakah sedang login?).
  3. Coba ubah status tersebut dari true menjadi false.
  4. Gunakan typeof untuk memastikan tipe datanya.
