Materi 28: Variabel (let, const, var)

Variabel adalah "kontainer" atau wadah untuk menyimpan data agar bisa kita gunakan nanti.

📝 Tugas Mentor:

  1. Buka script.js.
  2. Buat variabel menggunakan let dan coba ubah nilainya.
  3. Buat variabel menggunakan const dan coba ubah nilainya (lihat apa yang terjadi!).
  4. Pelajari kenapa kita sebaiknya tidak lagi menggunakan var.
Catatan: const itu seperti janji setia, sekali kamu kasih nilai, dia nggak mau ganti!
