Materi 26: Tipe Data Primitif & Console

Selamat datang di dunia JavaScript, Garda! Di sini kita akan belajar cara "berbicara" dengan komputer melalui console.

📝 Tugas Mentor:

  1. Buka file script.js di folder ini.
  2. Gunakan console.log() untuk mencetak nama kamu.
  3. Coba cetak angka favoritmu.
  4. Buka browser, lalu tekan F12 atau Ctrl+Shift+I (Inspect Element) dan cari tab Console untuk melihat hasilnya.

Tips: Komputer itu sangat patuh, tapi dia juga sangat kaku. Salah satu huruf atau tanda kurung saja, dia bisa bingung (error)!
