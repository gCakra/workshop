🎯 Game Tebak Angka

Buka script.js dan ikuti instruksinya!

Semua output akan muncul di console dan prompt/alert.

Konsep yang dipakai:
  • while loop — perulangan selama kondisi true
  • break — menghentikan loop saat tebakan benar
  • prompt() — meminta input dari user
  • Math.random() & Math.floor() — membuat angka acak
